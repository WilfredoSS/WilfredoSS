### 📈 Proyectos Destacados e Impacto Real

#### 1. **DinamiGO** — *Plataforma de Movilidad y Delivery en Producción*
*Ecosistema de producción para la gestión logística de última milla operado activamente.*
* **Mobile:** Arquitectura nativa en Android utilizando **Kotlin y Jetpack Compose** para garantizar una interfaz de alto rendimiento y bajo consumo de recursos.
* **Backend:** Servicios y APIs REST con **Node.js y Express**, gestionando alta concurrencia mediante **MongoDB**.
* **Infraestructura:** Administración completa en servidores **Linux VPS (Ubuntu)** con **Apache** y **PM2**, garantizando una disponibilidad superior al 99% mediante scripts de automatización.

#### 2. **UrbanRide Logistics** — *Ecosistema Transaccional de Movilidad y Geolocalización*
*Monorepositorio diseñado para la gestión de transporte en tiempo real bajo condiciones de red variables.*
* **Sincronización & GPS:** Comunicación bidireccional cliente-servidor para el rastreo y despacho continuo de viajes mediante WebSockets.
* **Persistencia Híbrida & Offline-First:** Arquitectura de datos con **MySQL** para la coherencia transaccional de pagos y **MongoDB** para telemetría. Implementación de **Room** en Android para garantizar la operatividad sin conexión a internet.

#### 3. **Gaming Tournament Platform** — *Marketplace Competitivo en Tiempo Real*
*Plataforma desacoplada para la organización y ejecución de torneos de videojuegos de formato dinámico.*
* **Service Layer & Validación Estricta:** Backend en Node.js con separación clara de capas y validación/sanitización del payload en el punto de entrada mediante **Zod**.
* **WebSockets & Brackets:** Asignación dinámica de salas (`Rooms`) para chat persistido en MongoDB e inyección instantánea del árbol de emparejamientos (*brackets*) en la app Android al iniciar el evento.
* **UI Dinámica:** App nativa con **Jetpack Compose** que adapta sus vistas de forma dinámica según las reglas en formato JSON recibidas desde la base de datos.

### 🧠 Filosofía de Desarrollo

* **Arquitectura Desacoplada:** Aplico Clean Architecture y el patrón Service Layer para asegurar que la lógica de negocio permanezca independiente de frameworks, bases de datos o librerías de interfaz.
* **Persistencia Inteligente:** Utilizo el motor de datos adecuado para cada necesidad: esquemas relacionales para consistencia transaccional (ACID) y motores NoSQL/In-Memory para alta velocidad y eventos de tiempo real.
* **Criterio de Producto:** Cada línea de código responde a un requerimiento operativo real: optimización de memoria, tolerancia a fallos de red y código mantenible a largo plazo.
